# Prasthara

First iteration of the Prasthara website — textile thrifting and upcycling.

## Live site

**https://msiddhesh008.github.io/prasthara/**

## Local development

```bash
cd frontend
npm install
npm run dev
```

## Deploy updates

From the repo root:

```bash
./scripts/deploy.sh
```

Or from `frontend`:

```bash
npm run deploy
```

This builds the site and publishes it to the `gh-pages` branch (GitHub Pages).
